# 📊 Employee Attendance Analysis Dashboard Project

This project uses a fictional (dummy) dataset created for portfolio purposes. It demonstrates employee attendance data management, analysis, reporting, and dashboard development using Microsoft Excel. No actual company or employee data is included, ensuring full confidentiality and data privacy.

- Created a realistic employee attendance dataset
- Validated and standardized attendance records
- Performed attendance and overtime analysis
- Built an interactive HR attendance dashboard
- Generated attendance reports for HR monitoring

## 🎯 Project Objectives

- Create a realistic employee attendance dataset.
- Validate attendance records.

- Analyze attendance trends.

- Generate attendance reports for HR monitoring.

---

## 📌 Project Overview

This project demonstrates the process of managing, analyzing, and reporting employee attendance data using Microsoft Excel.

The attendance dataset was created from the Employee Master dataset and contains employee attendance records for **June 2026**.

The workbook includes employee master data, raw attendance records, validation and cleaning processes, a final clean dataset, and an interactive dashboard designed to support HR attendance monitoring and decision-making.
